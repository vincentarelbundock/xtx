Benchmarks

How much time does it save to skip the dense model matrix? This page times six common operations twice: once with base R, which builds the full matrix first, and once with xtx, which works from the design matrix instead. The data have 200,000 rows, the model matrix has 119 columns, and everything runs on one thread. The answer depends on what the columns are, so there are two models: one with factors, one with numeric variables only.

Each operation is timed in two situations:

  • From a data frame. The matrix is built and then used once, as when predicting on a new batch of data.
  • From a prebuilt design matrix. The matrix already exists and only the operation is timed, as when the same matrix is used again and again. Base R starts from its own prebuilt dense matrix.

A third panel times model fits: lm() and glm() against lm_xtx() and glm_xtx() from xtx.fit, and, for the model with factors, predictions on new data, their standard errors and leverage from a fitted lm(), against the same quantities computed on the design matrix.

Shorter bars are better.

Numeric and factors

The model is y ~ x * f1 + f2, with a factor of 50 levels and one of 20. All but two of its 119 columns are factor dummies and their interactions with x, so each row has only a few non-zero entries, which xtx skips.

For crossprod(D), the design matrix adds up the products of each row’s few non-zero entries, instead of all p^2 / 2 products of the dense row. For quadratic_diagonal(), base R builds an n by p intermediate, where the kernel touches only the non-zero entries of each row. Examples and benchmarks of threads, reuse on new data, sparse matrices and repeated rows are in the Algebra recipes.

Numeric only

The model has 118 numeric variables and an intercept: as many columns, but no zeros to skip. For the matrix operations, xtx has nothing to gain: the two are close on every operation, each a little ahead on some. The model fits are another matter: lm_xtx() and glm_xtx() remain several times faster than lm() and glm() (the third panel), because they factor the small p by p cross-product instead of the n by p matrix. glm_xtx() does that once per iteration.

Two things still set xtx apart:

  • The dense matrix is always available. as.matrix(design_matrix()) returns the same matrix as model.matrix(), bit for bit, in about the same time (the first pair of bars). Code that needs the dense matrix of a numeric model can build it at no extra cost.
  • The same code runs out of core. A design can be built on a DuckDB table or on Parquet files that do not fit in memory, where there is no dense matrix to fall back on: see Out-of-core data.

Other pages have their own benchmarks: fixed effects, least squares, leverage, standard errors and predictions.

Setup

The benchmarks of this site run on this data, with one thread unless stated otherwise. X and DX are prebuilt dense and design matrices, and same() and close() are the checks for exact and approximate results. Each benchmark runs in a fresh R process on top of this setup; the results shown were saved by make bench (see website/benchmarks).

The benchmark tables report minimum and median elapsed time and mem_alloc, the total bytes allocated on the R heap during one evaluation. Reproducing the memory column requires an R build with capabilities("profmem") enabled. For fair comparisons with functions that call model.matrix(), the benchmarks set options(xtx.skip_na_copy = FALSE), so that the model frame is built in exactly the same way (by default, xtx skips a copy of the frame that na.omit() makes even when no row has a missing value).

Code

These are the scripts themselves, read from website/benchmarks/ when the site is built. run.R runs each benchmark in a fresh R process, on top of setup.R, and saves its results as a CSV file, which the charts above read.

setup.R:

library(xtx)
options(xtx.threads = 1)
# Build the model frame exactly as model.matrix() does, so that comparisons
# with functions that call it are fair, and compute every row.
options(xtx.skip_na_copy = FALSE, xtx.dedup = FALSE)

# BENCH_SIZE=quick (make bench-quick) checks the scripts on fewer rows and
# at most 3 iterations; run.R then saves the results outside results/.
quick <- identical(Sys.getenv("BENCH_SIZE", "full"), "quick")
iters <- function(k) if (quick) min(k, 3) else k

set.seed(1)
n <- if (quick) 2e4 else 2e5
big <- data.frame(
    y = rnorm(n),
    x = rnorm(n),
    f1 = factor(sample(sprintf("a%02d", 1:50), n, TRUE)),
    f2 = factor(sample(letters[1:20], n, TRUE)),
    cl = sample(1:1000, n, TRUE))
fo <- y ~ x * f1 + f2

# Prebuilt dense and design matrices, and a fitted model
X <- model.matrix(fo, big)
DX <- design_matrix(fo, big)
delayedAssign("fit_big", lm(fo, big))
delayedAssign("spec_big", design_matrix(fit_big, newdata = NULL))

# Checks for exact and approximate results
same <- function(a, b) identical(a, b, num.eq = FALSE, single.NA = FALSE, attrib.as.set = FALSE)
flat <- function(v) unname(c(unlist(v)))
close <- function(a, b) isTRUE(all.equal(flat(a), flat(b)))

fast_predict <- function(fit, newdata, spec) {
    D <- design_matrix(spec, newdata)
    drop(D %*% coef(fit))
}

base_predict_se <- function(fit, newdata) {
    predict(fit, newdata, se.fit = TRUE)$se.fit
}
fast_predict_se <- function(fit, newdata, spec) {
    D <- design_matrix(spec, newdata)
    sqrt(quadratic_diagonal(D, vcov(fit)))
}

bench::mark(

numeric.R:

# A purely numeric design: 118 numeric columns and an intercept, as many
# columns as the design with factors of the other benchmarks. Returns one
# row per operation, starting point and package: the median time in
# milliseconds. The last rows are model fits: lm() and glm() against
# lm_xtx() and glm_xtx() (package xtx.fit).
library(xtx.fit)
p <- 118
num <- as.data.frame(matrix(rnorm(n * p), n, p))
names(num) <- paste0("x", seq_len(p))
fn <- reformulate(names(num), "y")
num$y <- rnorm(n)
num$yb <- as.integer(num$y + num$x1 > 0)
fb <- reformulate(names(num)[seq_len(p)], "yb")
Xn <- model.matrix(fn, num)
Dn <- design_matrix(fn, num)

beta <- rnorm(ncol(Xn))
w <- rnorm(n)
g <- sample(1:20, n, TRUE)
V <- crossprod(matrix(rnorm(ncol(Xn)^2), ncol(Xn))) / ncol(Xn)
base_diagonal <- function(X, V) rowSums((X %*% V) * X)

# Each operation: base R then xtx from the data frame, then (but for the
# first) base R then xtx from the prebuilt matrix
time <- function(operation, ..., check = close, iterations = 10,
                 start = c("From a data frame", "From a prebuilt design matrix")) {
    res <- bench::mark(..., iterations = iters(iterations), check = check)
    data.frame(operation = operation,
               start = rep(start, each = 2)[seq_len(nrow(res))],
               package = rep(c("Base R, dense matrix", "xtx, design matrix"), length.out = nrow(res)),
               ms = signif(as.numeric(res$median) * 1000, 3))
}
rbind(
    time("Build the dense matrix",
         model.matrix(fn, num),
         as.matrix(design_matrix(fn, num)), check = same),
    time("%*%",
         model.matrix(fn, num) %*% beta,
         design_matrix(fn, num) %*% beta,
         Xn %*% beta,
         Dn %*% beta),
    time("crossprod(D, w)",
         crossprod(model.matrix(fn, num), w),
         crossprod(design_matrix(fn, num), w),
         crossprod(Xn, w),
         crossprod(Dn, w)),
    time("crossprod(D)",
         crossprod(model.matrix(fn, num)),
         crossprod(design_matrix(fn, num)),
         crossprod(Xn),
         crossprod(Dn)),
    time("colSums(w * D, group = )",
         rowsum(w * model.matrix(fn, num), g),
         colSums(w * design_matrix(fn, num), group = g),
         rowsum(w * Xn, g),
         colSums(w * Dn, group = g)),
    time("quadratic_diagonal()",
         base_diagonal(model.matrix(fn, num), V),
         quadratic_diagonal(design_matrix(fn, num), V),
         base_diagonal(Xn, V),
         quadratic_diagonal(Dn, V), iterations = 5),
    time("lm()",
         coef(lm(fn, num)),
         coef(lm_xtx(fn, num)), start = "Model fits, from a data frame"),
    time("glm(, binomial)",
         coef(glm(fb, binomial, num)),
         coef(glm_xtx(fb, binomial, num)), iterations = 5, start = "Model fits, from a data frame"))

run.R:

# Run the website benchmarks and save their results in results/.
#
#   Rscript website/benchmarks/run.R              # every benchmark
#   Rscript website/benchmarks/run.R crossprod qr # only these
#   BENCH_SIZE=quick Rscript website/benchmarks/run.R   # quick check
#
# Each benchmark runs in a fresh R process, on top of setup.R, and returns
# either a bench::mark() result, saved as its expression, min, median and
# mem_alloc columns, a data frame, saved as is, or NULL (nothing to save:
# the script saved its own files). The website reads these files and never
# runs a benchmark itself.
#
# BENCH_SIZE is "full" (the default: the published results) or "quick"
# (make bench-quick): fewer rows and iterations (setup.R) and a small
# fixed-effects grid (fixed_effects.R), to check that the scripts run. Quick
# results never go to results/: they go to $BENCH_OUT/website (default
# $TMPDIR/xtx-bench-quick, or /tmp/...), printed at the end. The
# workers get the folder as BENCH_RESULTS.
#
# The BLAS runs on one thread (OMP_NUM_THREADS=1, since OpenBLAS built with
# OpenMP ignores OPENBLAS_NUM_THREADS). The option xtx.threads is capped by the same
# OpenMP limit, so the benchmarks that time several threads run without it.
multithreaded <- c("threads")

args <- commandArgs(trailingOnly = FALSE)
here <- dirname(normalizePath(sub("^--file=", "", grep("^--file=", args, value = TRUE))))
self <- file.path(here, "run.R")
setwd(here)
wanted <- commandArgs(trailingOnly = TRUE)
bench_size <- Sys.getenv("BENCH_SIZE", "full")
if (!bench_size %in% c("full", "quick")) stop("BENCH_SIZE must be \"full\" or \"quick\", not \"", bench_size, "\"")

summarize <- function(out) {
    if (!inherits(out, "bench_mark")) return(out)
    data.frame(
        expression = format(out$expression),
        min = format(out$min),
        median = format(out$median),
        mem_alloc = format(out$mem_alloc))
}

if (identical(wanted[1], "--one")) {
    # Worker: run one benchmark in this process.
    s <- wanted[2]
    shared <- new.env()
    sys.source("setup.R", envir = shared)
    set.seed(1)
    out <- eval(parse(paste0(s, ".R")), new.env(parent = shared))
    if (!is.null(out)) {
        write.csv(summarize(out), file.path(Sys.getenv("BENCH_RESULTS", "results"), paste0(s, ".csv")),
                  row.names = FALSE)
    }
    quit(save = "no")
}

if (!capabilities("profmem")) {
    warning("this R build lacks profmem support: the mem_alloc column will be NA", call. = FALSE)
}

scripts <- setdiff(sub("\\.R$", "", list.files(".", "\\.R$")), c("setup", "run"))
if (length(wanted) > 0) {
    unknown <- setdiff(wanted, scripts)
    if (length(unknown) > 0) stop("unknown benchmark(s): ", paste(unknown, collapse = ", "))
    scripts <- wanted
}
results <- if (bench_size == "full") file.path(here, "results") else {
    tmp <- Sys.getenv("TMPDIR")
    out <- Sys.getenv("BENCH_OUT")
    if (!nzchar(out)) out <- file.path(if (nzchar(tmp)) tmp else "/tmp", "xtx-bench-quick")
    file.path(out, "website")
}
dir.create(results, showWarnings = FALSE, recursive = TRUE)
results <- normalizePath(results)

rscript <- file.path(R.home("bin"), "Rscript")
for (s in scripts) {
    message("running ", s)
    env <- c("OPENBLAS_NUM_THREADS=1", if (!s %in% multithreaded) "OMP_NUM_THREADS=1",
             paste0("BENCH_SIZE=", bench_size), paste0("BENCH_RESULTS=", shQuote(results)))
    status <- system2(rscript, c(shQuote(self), "--one", s), env = env)
    if (status != 0) stop("benchmark ", s, " failed")
}

writeLines(c(
    R.version.string,
    paste("cores:", parallel::detectCores()),
    paste("BLAS:", basename(extSoftVersion()[["BLAS"]]), "(one thread)"),
    paste("run:", format(Sys.Date()), if (bench_size == "quick") "(quick: BENCH_SIZE=quick)")),
    file.path(results, "machine.txt"))
if (bench_size == "quick") message("quick results in ", results)
