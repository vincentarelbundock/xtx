Fixed effects

Usage

Fixed effects go after a | in the formula, as in fixest. The same model, fitted with both packages on a dataset that comes with fixest:

library(fixest)
library(xtx.fit)
data(trade)

fit1 <- feols(log(Euros) ~ log(dist_km) | Origin + Destination + Year, trade)
fit2 <- lm_xtx(log(Euros) ~ log(dist_km) | Origin + Destination + Year, trade)

coef(fit1)
log(dist_km) 
   -2.072969
coef(fit2)
log(dist_km) 
   -2.072969
all.equal(c(vcov(fit1)), c(vcov(fit2)))
[1] TRUE

See lm_xtx() for the options (clustered standard errors, predictions, the values of the fixed effects) and glm_xtx(), which takes the same formulas, for generalized linear models.

Benchmark

How fast is lm_xtx() with fixed effects, compared with the other R packages that fit linear models with high-dimensional fixed effects? This page replicates the fixed-effects OLS benchmark of pyfixest, itself adapted from Kyle Butts’ fixest_benchmarks, for R packages only.

Data generating processes

Every dataset is simulated from the same model:

𝑦=∑𝑗=1𝑘𝑥𝑗𝛽𝑗+𝛼indiv+𝛿year+𝛾group+𝜀.

The balanced panel has no group effect. The processes differ in how individuals are matched with years and groups.

Balanced panel

States observed every year. Each state has one row per year, without gaps: every state appears in every year.

  • States or countries observed every year.
  • Stores with sales recorded every week.
  • The subjects of an experiment, measured in every round.
n_indiv <- 10000; n_year <- 10       # indiv_id: the state
d <- data.frame(indiv_id = rep(1:n_indiv, each = n_year), year = rep(1:n_year, n_indiv))
d$x1 <- rnorm(nrow(d))
d$y <- d$x1 + rnorm(n_indiv)[d$indiv_id] + rnorm(n_year)[d$year] + rnorm(nrow(d))
lm_xtx(y ~ x1 | indiv_id + year, d)

Random matching

Shoppers and the products they buy. Every week, each shopper buys one product, picked at random among all the products, whatever they bought the week before. Over time, a shopper goes through many different products.

  • Shoppers and the products they buy, or viewers and the films they rate.
  • Freelancers or temporary workers and the many clients they work for.
  • Callers and the call-centre agents who answer them.
n_indiv <- 10000; n_year <- 10; n_group <- 435   # indiv_id: the shopper, year: the week, group_id: the product
d <- data.frame(indiv_id = rep(1:n_indiv, each = n_year), year = rep(1:n_year, n_indiv))
d$group_id <- sample(n_group, nrow(d), replace = TRUE)
d$x1 <- rnorm(nrow(d))
d$y <- d$x1 + rnorm(n_indiv)[d$indiv_id] + rnorm(n_year)[d$year] + rnorm(n_group)[d$group_id] + rnorm(nrow(d))
lm_xtx(y ~ x1 | indiv_id + year + group_id, d)

Round robin

Students and their teachers. Every year, each student moves up to the next teacher in line, as a class moves up to the teacher of the grade above. Over time, a student has a run of consecutive teachers. Students who start with different teachers follow the same line, a few teachers ahead or behind. In the simulated data the line closes into a loop: after the last teacher comes the first.

  • Students passed from the teachers of one grade to those of the next.
  • Medical residents rotating through wards, or staff on a fixed rota.
  • Surveys that rotate overlapping cohorts.
n_indiv <- 10000; n_year <- 10; n_group <- 435   # indiv_id: the student, group_id: the teacher
d <- data.frame(indiv_id = rep(1:n_indiv, each = n_year), year = rep(1:n_year, n_indiv))
d$group_id <- rep_len(1:n_group, nrow(d))
d$x1 <- rnorm(nrow(d))
d$y <- d$x1 + rnorm(n_indiv)[d$indiv_id] + rnorm(n_year)[d$year] + rnorm(n_group)[d$group_id] + rnorm(nrow(d))
lm_xtx(y ~ x1 | indiv_id + year + group_id, d)

Low mobility

Workers and their firms. Workers stay at the same firm from one year to the next and change only now and then: each year, a worker leaves for another firm, picked at random, with a small probability.

  • Workers and firms in matched employer-employee data.
  • Patients and their physicians.
  • Students and their schools.
n_indiv <- 10000; n_year <- 10; n_group <- 435   # indiv_id: the worker, group_id: the firm
d <- data.frame(indiv_id = rep(1:n_indiv, each = n_year), year = rep(1:n_year, n_indiv))
# a new spell in a worker's first year, and when they move (8% of years)
spell <- cumsum(d$year == 1 | runif(nrow(d)) < 0.08)
d$group_id <- sample(n_group, max(spell), replace = TRUE)[spell]
d$x1 <- rnorm(nrow(d))
d$y <- d$x1 + rnorm(n_indiv)[d$indiv_id] + rnorm(n_year)[d$year] + rnorm(n_group)[d$group_id] + rnorm(nrow(d))
lm_xtx(y ~ x1 | indiv_id + year + group_id, d)

Algorithms

  • fixest and pyfixest demean the data by alternating projections: they subtract the means of each fixed effect in turn from the outcome and from every regressor, sweeping over the rows until nothing changes, then run least squares on the demeaned data. The number of sweeps depends on how individuals are matched with groups: one on a balanced panel, a few with random matching, many with round robin.
  • xtx.fit never demeans. A fixed number of passes over the rows computes sums (cross-products of the regressors, their sums within each level, and counts of the levels that occur together), then a linear system over the levels of the fixed effects is solved: the largest fixed effect is eliminated exactly, the others by a direct factorization (up to 1,000 levels) or by conjugate gradients. options(xtx.fe_precond = "jacobi") or "ichol" forces a preconditioner, and xtx.fe_form_max sets when the reduced system is formed (0 never, Inf always).

The time of the first grows with the number of sweeps, so with the data generating process; the time of the second depends on it much less.

Solver

lm_xtx(y ~ x | f1 + f2) absorbs the fixed effects without demeaning (R/absorb.R and src/fe_solver.c of xtx.fit, on the grouped sums and crosstabs of xtx, src/fe.c; the fit in R/fe.R). Write the model 𝑦=𝑋𝑏+𝐹𝑎+𝑒, with 𝐹 the dummies of the 𝐾 fixed effects and 𝑊 the weights. With

𝑆=𝐹′𝑊𝑋,𝑠=𝐹′𝑊𝑦,𝐾=𝐹′𝑊𝐹,

the Frisch-Waugh-Lovell moments are

𝑋′𝑀𝑋=𝑋′𝑊𝑋−𝑆′𝐾−𝑆,𝑋′𝑀𝑦=𝑋′𝑊𝑦−𝑆′𝐾−𝑠.

Every input is a sum over rows: 𝑋′𝑊𝑋 and 𝑋′𝑊𝑦 are products with the design, 𝑆 and 𝑠 are grouped sums, and 𝐾 has the level counts on its diagonal blocks and the crosstabs of pairs of fixed effects off the diagonal. The remaining work is the solve with 𝐾, whose size is the number of levels and not the number of rows:

  • the largest fixed effect is eliminated analytically, since its block of 𝐾 is diagonal;
  • the Schur complement over the other fixed effects is a sparse, symmetric, singular system whose diagonal blocks are weighted graph Laplacians. One level per connected component is set to zero;
  • it is solved by a pivoted dense Cholesky factorization when small (which also gives the rank), and otherwise by conjugate gradients: on the formed matrix with an incomplete Cholesky preconditioner when mobility between levels is low and the matrix is sparse, or without forming it, with a diagonal preconditioner, when it would be near dense. A probe of a few columns chooses between the two.

The same solve gives the values of the fixed effects. The coefficients are then refined from residuals computed row by row, which corrects the rounding of the one-pass sums. Cluster-robust scores are also sums: grouped column sums of 𝑤𝑒𝑋, minus a correction from the crosstab of clusters and fixed effects.

For a GLM with fixed effects, the weighted least squares step of each IRLS iteration is this estimator, with the working weights (R/fe_glm.R). The reduced system changes a little at each iteration, so conjugate gradients start from the previous solution.

Remotely, the database returns the grouped sums and crosstabs and R solves the reduced system. The fit scales with the number of levels and of non-empty crosstab cells, which must fit in memory, and not with the number of rows.

Accuracy

Largest absolute difference between each package’s coefficients and those of feols() at a tight tolerance, over every fit.

Protocol

  • Data. 1,000 to 1 million observations with ten regressors: for 𝑛 observations, 𝑛/10 individuals over 10 years and 𝑛/230 groups. Each dataset is simulated once and saved as a Parquet file.
  • Models. y ~ x1 + ... + x10 | indiv_id + year on the balanced panel, with + group_id on the other processes; iid standard errors.
  • One thread. Every package and the BLAS run on one thread, and the whole run is pinned to one CPU core.
  • Time. Each fit runs in a fresh R process: one warmup fit, then the median of three. In-memory fits read the data before the clock starts; DuckDB fits query the Parquet file, so their time includes reading it.
  • Memory. Peak resident memory during the warmup fit, over its level just before. The data frame of the in-memory fits is not counted.
  • Limits. A fit that takes more than 2 minutes is timed once, and the package is not run at larger sizes. A fit is stopped after 30 minutes (10 minutes for dbreg (DuckDB) on round robin). dbreg() runs with its limit of alternating projections raised from 100 to 10,000.
  • Accuracy. Coefficients are compared with those of feols() at a tight tolerance (fixef.tol = 1e-11), fitted outside the timed runs.
CPU: 13th Gen Intel(R) Core(TM) i9-13900K (one core, one thread)

Code

The benchmark is website/benchmarks/fixed_effects.R. It simulates each dataset once with fixed_effects/simulate.R and this function:

# The data of the fixed-effects benchmark (see ../fixed_effects.R), shared by
# simulate.R (which saves each dataset once, as Parquet), cell.R (timed fits)
# and reference.R (tight-tolerance coefficients).
#
# Four data generating processes, adapted from Kyle Butts' fixest_benchmarks
# (as used by pyfixest). Each is a panel of individuals over 10 years, with
# k standard normal regressors; in all but the first, every row also belongs
# to a group, with about 23 individuals per group and year:
#
# * "balanced": individuals and years only (states observed every year).
# * "random": each row's group is drawn at random (shoppers and the
#   products they buy).
# * "round_robin": groups are assigned in turn over the rows, so every
#   individual moves to the next group every year (students moving up to
#   the next teacher).
# * "low_mobility": individuals keep their group and move to another one,
#   drawn at random, in 8% of years (workers and their firms).
#
# The model fitted has individual and year effects, and group effects when
# the process has groups (fe_formula()).
fe_processes <- c("balanced", "random", "round_robin", "low_mobility")

dgp <- function(n, type, k, seed = 42) {
    type <- match.arg(type, fe_processes)
    set.seed(seed)
    nb_year <- 10
    nb_indiv <- round(n / nb_year)
    nb_group <- round(nb_indiv / 23)
    n <- nb_indiv * nb_year
    indiv_id <- rep(seq_len(nb_indiv), each = nb_year)
    year <- rep(seq_len(nb_year), nb_indiv)
    group_id <- switch(type,
        balanced = NULL,
        random = sample.int(nb_group, n, TRUE),
        round_robin = rep_len(seq_len(nb_group), n),
        low_mobility = {
            # a new spell in an individual's first year, and when they move
            spell <- cumsum(year == 1 | runif(n) < 0.08)
            sample.int(nb_group, max(spell), TRUE)[spell]
        })
    # x1..xk ~ N(0, 1), column by column (same draws as an n by k matrix)
    d <- data.frame(y = numeric(n))
    y <- numeric(n)
    for (j in seq_len(k)) {
        x <- rnorm(n)
        d[[paste0("x", j)]] <- x
        y <- y + x / j
    }
    y <- y + rnorm(nb_indiv)[indiv_id] + rnorm(nb_year)[year]
    if (!is.null(group_id)) y <- y + rnorm(nb_group)[group_id]
    d$y <- y + rnorm(n)
    d$indiv_id <- indiv_id
    d$year <- year
    d$group_id <- group_id
    d
}

# The fixed effects of a process: individuals and years, and its groups
fe_ids <- function(type) c("indiv_id", "year", if (type != "balanced") "group_id")

# A Parquet file of simulate.R holds the data of one process and size for
# several k: x1..x_max(k) and the ids are the same draws whatever k (they
# come first in the random stream), and the response for k regressors is
# column y_<k>. This query gives exactly dgp(n, type, k): y, x1..xk, then
# the ids, in that order.
fe_sql <- function(path, type, k) {
    sprintf("SELECT y_%d AS y, %s, %s FROM read_parquet('%s')",
            as.integer(k), paste0("x", seq_len(k), collapse = ", "),
            paste(fe_ids(type), collapse = ", "), gsub("'", "''", path))
}

# The data for k regressors as a data frame (in-memory fits)
fe_read <- function(path, type, k) {
    con <- DBI::dbConnect(duckdb::duckdb())
    on.exit(DBI::dbDisconnect(con, shutdown = TRUE))
    DBI::dbExecute(con, "SET threads = 1")
    DBI::dbGetQuery(con, fe_sql(path, type, k))
}

fe_formula <- function(type, k) {
    xs <- paste0("x", seq_len(k))
    f <- as.formula(paste("y ~", paste(xs, collapse = " + "), "|", paste(fe_ids(type), collapse = " + ")))
    environment(f) <- globalenv()
    f
}

Each fit runs in a fresh R process with this script (the reference fits run separately, in fixed_effects/reference.R):

# One cell of the fixed-effects benchmark (see ../fixed_effects.R), in a fresh
# R process:
#
#   Rscript cell.R <package> <data.parquet> <dgp> <k> <limit> <out.csv>
#
# Reads the data that simulate.R saved (dgp.R): into a data frame for the
# in-memory packages, or as a DuckDB view that queries the Parquet file for
# the DuckDB ones. Then fits the model once (warmup), then three timed times,
# and writes one row to <out.csv>: the median time in seconds, the extra peak
# resident memory of the warmup call in MB, and the coefficients. When the
# warmup takes more than <limit> seconds, its time is reported alone (reps =
# 0) instead of three more runs. If the warmup fails, the row says so
# (fit_status = "error") with the seconds it took to fail. The reference
# coefficients are computed separately (reference.R).
args <- commandArgs(trailingOnly = TRUE)
here <- dirname(sub("^--file=", "", grep("^--file=", commandArgs(FALSE), value = TRUE)))
source(file.path(here, "dgp.R"))
package <- args[1]
path <- args[2]
dgp_type <- args[3]
k <- as.integer(args[4])
limit <- as.numeric(args[5])
out <- args[6]

xs <- paste0("x", seq_len(k))
f <- fe_formula(dgp_type, k)

# The data: DuckDB runs on one thread, as every package below
remote <- package %in% c("lm_xtx (DuckDB)", "dbreg (DuckDB)")
if (remote) {
    # A view, so that every query reads the Parquet file: the rows are never
    # loaded into the database or into R
    suppressMessages({
        con <- DBI::dbConnect(duckdb::duckdb())
        DBI::dbExecute(con, "SET threads = 1")
        DBI::dbExecute(con, paste("CREATE VIEW d AS", fe_sql(path, dgp_type, k)))
    })
    nrows <- DBI::dbGetQuery(con, "SELECT count(*) AS n FROM d")$n
} else {
    d <- fe_read(path, dgp_type, k)
    nrows <- nrow(d)
}

# Every package on one thread
suppressPackageStartupMessages(switch(package,
    "lm_xtx" = ,
    "lm_xtx (DuckDB)" = {
        library(xtx)
        library(xtx.fit)
        options(xtx.threads = 1)
    },
    "feols" = {
        library(fixest)
        setFixest_nthreads(1)
        data.table::setDTthreads(1)
    },
    "dbreg (DuckDB)" = {
        library(dbreg)
        # The default (100 iterations of alternating projections) stops with
        # an error on round robin.
        options(dbreg.ap_max_iter = 1e4)
    },
    stop("unknown package: ", package)))

fit <- switch(package,
    "lm_xtx" = function() lm_xtx(f, d),
    "lm_xtx (DuckDB)" = function() lm_xtx(f, con, table = "d"),
    "feols" = function() feols(f, d, vcov = "iid", notes = FALSE),
    "dbreg (DuckDB)" = function() dbreg(f, conn = con, table = "d", vcov = "iid"))

# Peak resident memory of this process (Linux): reset the high-water mark,
# then read it after the call.
status_mb <- function(field) {
    line <- grep(paste0("^", field, ":"), readLines("/proc/self/status"), value = TRUE)
    as.numeric(gsub("\\D", "", line)) / 1024
}

# One row of results, written to a temporary file then renamed, so that a
# process stopped while writing never leaves a truncated <out.csv>.
save_row <- function(...) {
    row <- data.frame(package = package, dgp = dgp_type, n = nrows, k = k, ...)
    part <- paste0(out, ".part")
    write.csv(row, part, row.names = FALSE)
    invisible(file.rename(part, out))
}

invisible(gc())
writeLines("5", "/proc/self/clear_refs")
rss0 <- status_mb("VmRSS")
start <- Sys.time()
t0 <- tryCatch(system.time(model <- fit())[["elapsed"]], error = function(e) {
    message("fit failed: ", conditionMessage(e))
    NULL
})
if (is.null(t0)) {
    save_row(seconds = NA_real_, reps = NA_integer_, mem_mb = NA_real_,
             coef = NA_character_, fit_status = "error",
             fit_seconds = as.numeric(difftime(Sys.time(), start, units = "secs")))
    quit(save = "no", status = 1)
}
mem_mb <- status_mb("VmHWM") - rss0
b <- coef(model)[xs]

if (t0 > limit) {
    seconds <- t0
    reps <- 0L
} else {
    rm(model)
    times <- replicate(3, system.time(fit())[["elapsed"]])
    seconds <- median(times)
    reps <- 3L
}

save_row(seconds = seconds, reps = reps, mem_mb = round(mem_mb, 1),
         coef = paste(sprintf("%.17g", b), collapse = ";"), fit_status = "ok", fit_seconds = t0)
